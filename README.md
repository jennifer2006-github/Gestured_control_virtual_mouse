# Gesture Controlled Virtual Mouse 🖐️🖱️

A computer vision based virtual mouse that allows users to control mouse actions using hand gestures through a webcam.

## Features
- Hand tracking using MediaPipe
- Cursor movement
- Left/right click
- Double click
- Drag and drop
- Scroll control
- Brightness and volume control

## Technologies
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Run

Install dependencies:

```bash
pip install opencv-python mediapipe pyautogui numpy pycaw screen-brightness-control

Run : python Gesture_Controller.py
